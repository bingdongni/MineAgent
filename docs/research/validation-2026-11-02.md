## 已覆盖的行为

| 范围 | 回归证据 |
| --- | --- |
| 学习与探索 | 物理上下文去重、不同参数/前值/环境隔离、预测归一性、700 次固定种子随机干预、历史容量边界、规则漂移与检查点恢复 |
| 组合规划 | 分开学习的转换组合成新路线，步数限制，单次观察不参与复用，反例导致路线停用 |
| 技能迁移 | 动作和验收绑定到新目标，旧目标上的成功不能提前完成迁移技能，错误/未知/循环绑定拒绝执行，旧逐步骤覆盖可用 |
| 证据迁移 | 旧版调用方命名上下文不能恢复已确认适配器，内部审计事实不能替换冻结的探针观察，深层和过大参数在生命周期前被拒绝 |
| 模型协议与成本 | 内置会话类型保持与隔离、本地 HTTP 并发、旧扩展同步兼容、Anthropic 稳定缓存块、缓存写入字段、异常用量归一化 |
| 动作统计 | 工具查询和身体动作分开，异步待执行不计失败，终态回调幂等，取消和证据不足单独统计 |

本地 HTTP 测试不连接收费模型服务，不含真实账单测量。受控语义状态测试调用生产组件，但不等同于完整 Minecraft 世界测试。
